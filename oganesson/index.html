Oganesson (Og)

Element 118 of the periodic table: a noble gas, expected to be a gas at room temperature.

← 117 TennessinePeriodic table

What is oganesson?

Oganesson is a radioactive element and the heaviest made so far. Only a handful of atoms have ever been produced.

What is oganesson used for?

Research only.

Where the name comes from

In honour of the physicist Yuri Oganessian. The name was approved in 2016.

Place in the periodic table

Oganesson is element number 118. It sits in period 7 (row 7) of the periodic table, in group 18 (column 18), and belongs to the p-block. It is the last element known so far. Just before it comes tennessine (117). In the same column, radon is above it. Elements in one column tend to behave alike.

Family: Noble gases.

Physical properties

Too few atoms of oganesson have been made to measure its bulk properties. It is expected to be a gas at room temperature.

Inside the atom

An atom of oganesson has 118 protons in its nucleus and, when neutral, 118 electrons around it. The electrons are arranged in 7 shells: 2, 8, 18, 32, 32, 18, 8. The outermost shell holds 8 electrons. Written in full, the electron configuration is [Rn]7s2 7p6 5f14 6d10 (predicted).

One mole of oganesson weighs 295.216 grams, so a single gram contains about 2.04 × 1021 atoms.

The ring picture is a simple model that only counts the electrons in each shell. Real atoms do not look like this.
